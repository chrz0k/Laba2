# Задание 1

## Задача 1

### Текст задачи

**1.1. Точка координат.**

Создайте сущность Точка, расположенную на двумерной плоскости, которая описывается:

- Координата X: число
- Координата Y: число
- Может возвращать текстовое представление вида «{X;Y}»

Необходимо создать три точки с разными координатами и вывести на экран их текстовое представление.

### Алгоритм решения

1. Создается класс `Point` с двумя закрытыми полями `x` и `y` типа `double`. Доступ к ним осуществляется через открытые свойства `X` и `Y`.
2. Метод `ToString()` переопределяется и возвращает строку вида `{X;Y}` с помощью интерполяции строк. Фигурные скобки в интерполированной строке удваиваются (`{{` и `}}`), чтобы они выводились как обычные символы.
3. Пользователь вводит с клавиатуры координаты трех точек. Ввод проверяется классом `Validator`: допускаются только вещественные числа, при ошибке программа выводит сообщение и просит повторить ввод.
4. Создаются три объекта `Point`, и их текстовое представление выводится на экран.

Реализация класса:

```csharp
namespace Laba2;

internal class Point
{
    private double x;
    private double y;

    public Point(double x, double y)
    {
        X = x;
        Y = y;
    }

    public double X
    {
        get { return x; }
        set { x = value; }
    }

    public double Y
    {
        get { return y; }
        set { y = value; }
    }

    public override string ToString()
    {
        string s = $"{{{x};{y}}}";
        return s;
    }
}
```

# Задание 2

## Задача 1

### Текст задачи

**2.1. Прямая.**

Создайте сущность Линия, расположенную на двумерной плоскости, которая описывается:

- Координата начала: Точка
- Координата конца: Точка
- Может возвращать текстовое представление вида «Линия от {X1;Y1} до {X2;Y2}»

Для указания координат нужно использовать сущность Точка, разработанную в задании 1.1. Создайте линии со следующими характеристиками:

1. Линия 1 с началом в т. {1;3} и концом в т. {23;8}.
2. Линия 2, горизонтальная, на высоте 10, от точки 5 до точки 25.
3. Линия 3, которая начинается всегда там же, где начинается линия 1, и заканчивается всегда там же, где заканчивается линия 2. Таким образом, если положение первой или второй линии меняется, то меняется и третья линия.
4. После создания всех трех объектов измените координаты первой и второй линий, причем сделайте это таким образом, чтобы положение третьей линии соответствовало требованиям пункта 3.
5. Измените координаты первой линии так, чтобы при этом не изменились координаты третьей линии.

### Алгоритм решения

1. Создается класс `Line` с двумя закрытыми полями `start` и `end` типа `Point` и свойствами `StartPoint` и `EndPoint`. Метод `ToString()` возвращает строку вида `Линия от {X1;Y1} до {X2;Y2}`, используя текстовое представление точек.
2. Создаются четыре точки: `point1 {1;3}`, `point2 {23;8}`, `point3 {5;10}`, `point4 {25;10}`. Из них строятся линия 1 (`point1`, `point2`) и линия 2 (`point3`, `point4`).
3. Линия 3 создается из тех же объектов: `new Line(point1, point4)`. Так как `Point` является классом, то есть ссылочным типом, линия хранит не копии точек, а ссылки на те же объекты. Поэтому линия 3 всегда начинается там же, где линия 1, и заканчивается там же, где линия 2.
4. Для пункта 4 изменяются координаты самих объектов-точек (`point1.X = 52` и т. д.). Изменение видно во всех линиях, которые используют эти объекты, поэтому линия 3 продолжает соответствовать требованию пункта 3.
5. Для пункта 5 свойствам `StartPoint` и `EndPoint` первой линии присваиваются новые объекты `Point`. При этом меняются только ссылки внутри линии 1, а линия 3 продолжает ссылаться на старые точки, поэтому ее координаты не меняются.

Реализация класса:

```csharp
namespace Laba2;

internal class Line
{
    private Point start;
    private Point end;

    public Line()
    {
        start = new Point(0, 0);
        end = new Point(0, 0);
    }

    public Line(double a, double b, double c, double d)
    {
        start = new Point(a, b);
        end = new Point(c, d);
    }

    public Line(Point point1, Point point2)
    {
        start = point1;
        end = point2;
    }

    public Line(Line line)
    {
        start = line.start;
        end = line.end;
    }

    public Point StartPoint
    {
        get { return start; }
        set { start = value; }
    }

    public Point EndPoint
    {
        get { return end; }
        set { end = value; }
    }

    public override string ToString()
    {
        string s = $"Линия от {start} до {end}";
        return s;
    }
}
```

Основная часть решения:

# Задание 3

## Задача 1

### Текст задачи

**3.1. Студент.**

Создайте сущность Студент, которая описывается:

- Имя: строка
- Оценки: массив целых чисел
- Может возвращать текстовое представление вида «Имя: [оценка1, оценка2,…,оценкаN]»

Необходимо выполнить следующие задачи:

1. Создать студента Васю с оценками: 3, 4, 5.
2. Создать студента Петю и скопировать оценки Васи, присвоив содержимое поля с оценками Васи полю с оценками Пети.
3. Заменить первую оценку Пети на число 5. Вывести на экран строковое представление Васи и Пети. Объяснить результат.
4. Создать студента Андрея и скопировать ему оценки Васи так, чтобы изменение оценок Васи не влияло на Андрея.

### Алгоритм решения

1. Создается класс `Student` с закрытыми полями `name` (строка) и `grades` (массив `int[]`) и свойствами `Name` и `Grades`. Если в свойство `Grades` попытаются записать `null`, вместо него сохраняется пустой массив, чтобы методы класса не завершались ошибкой.
2. Метод `ToString()` формирует строку вида `Имя: [3, 4, 5]`. Если оценок нет, выводится `Имя: Без оценок`.
3. Создается Вася с оценками 3, 4, 5 и Петя без оценок. Затем выполняется присваивание `student2.Grades = student1.Grades`.
4. Первая оценка Пети заменяется на 5 (`student2.Grades[0] = 5`) и выводятся оба студента.
5. Для Андрея создается независимая копия массива: `student3.Grades = (int[])student1.Grades.Clone()`. После этого первая оценка Васи меняется на 2 (`student1.Grades[0] = 2`), и выводятся Вася и Андрей.

**Объяснение результата (пункт 3).** Массив является ссылочным типом. При присваивании `student2.Grades = student1.Grades` копируется не содержимое массива, а ссылка на него, поэтому у Васи и Пети поле с оценками указывает на один и тот же массив в памяти. Замена `student2.Grades[0] = 5` меняет этот общий массив, поэтому новая оценка отображается и у Пети, и у Васи.

Для Андрея метод `Clone()` создает новый массив с теми же значениями. У Андрея и Васи теперь разные массивы, и изменение оценок Васи на Андрея не влияет.

Реализация класса (поля, свойства и вывод):

```csharp
namespace Laba2;

internal class Student
{
    private string name;
    private int[] grades;

    public string Name
    {
        get { return name; }
        set
        {
            if (value != null)
            {
                name = value;
            }
            else
            {
                name = "Default";
            }
        }
    }

    public int[] Grades
    {
        get { return grades; }
        set { grades = value ?? new int[0]; }
    }

    public override string ToString()
    {
        string s = name + ": ";
        if (grades.Length == 0)
        {
            s += "Без оценок";
        }
        else
        {
            s += "[";
            for (int i = 0; i < grades.Length; i++)
            {
                if (i == grades.Length - 1)
                {
                    s += grades[i] + "]";
                }
                else
                {
                    s += grades[i] + ", ";
                }
            }
        }

        return s;
    }
}
```

Основная часть решения:

```csharp
Student student1 = new Student("Вася", [3, 4, 5]);
Student student2 = new Student("Петя");

student2.Grades = student1.Grades;
student2.Grades[0] = 5;

Student student3 = new Student("Андрей");
student3.Grades = (int[])student1.Grades.Clone();
student1.Grades[0] = 2;
```

**4.7. Создаем студента.**

Измените сущность Студент из задачи 3.1. Новые требования включают:

- Студента можно создать, указав только имя.

```csharp
public Student(string name, params int[] grades)
```

# Задание 5

## Задача 1

### Текст задачи

**5.6. Студент отличник.**

Измените сущность Студент из задачи 4.7. Новые требования включают:

- Студент может возвращать значение своей средней оценки (вещественное число). Если оценок нет, то среднее – 0.
- Студент может возвращать информацию о том, является ли он отличником или нет. Студент является отличником, если у него есть хотя бы одна оценка и все оценки только отличные.

Необходимо выполнить следующие задачи:

1. Создайте студента Васю с оценками 3, 4, 5, 4.
2. Создайте студента Петю с оценками 5, 5, 5, 5.
3. Выведите для обоих студентов информацию о среднем балле и являются ли они отличниками.

### Алгоритм решения

1. В класс `Student` добавляется метод `AverageGrade()`. Если оценок нет, он возвращает 0. Иначе в цикле считается сумма оценок, и она делится на их количество. Сумма предварительно приводится к типу `double`, чтобы деление было вещественным, а не целочисленным.
2. Добавляется метод `IsExcellent()`, возвращающий `bool`. Если оценок нет, возвращается `false`. Иначе оценки перебираются в цикле `foreach`: как только найдена оценка меньше 5, метод сразу возвращает `false`. Если цикл завершился без таких оценок, возвращается `true`.
3. Создаются студенты Вася (3, 4, 5, 4) и Петя (5, 5, 5, 5).
4. Для каждого студента выводится его текстовое представление, средний балл и текст о том, является ли он отличником. Текст выбирается в `Program` по значению, которое вернул `IsExcellent()`.

Реализация методов:

```csharp
public double AverageGrade()
{
    if (grades.Length <= 0)
    {
        return 0;
    }

    int sum = 0;
    for (int i = 0; i < grades.Length; i++)
    {
        sum += grades[i];
    }

    double averageGrade = (double)sum / grades.Length;
    return averageGrade;
}

public bool IsExcellent()
{
    if (grades.Length == 0)
    {
        return false;
    }

    foreach (int grade in grades)
    {
        if (grade < 5)
        {
            return false;
        }
    }

    return true;
}
```
